# Centro — Product Requirements Document: Overview

## Summary
Centro is a Philippine Subdivision Management System designed to streamline communication, dues collection, emergency alerting, and access control between residents, administrators, and security guards.

## Goals
- Provide a unified platform for subdivision stakeholders.
- Automate dues tracking and payment reminders.
- Enable real-time emergency alerts for security personnel.

## User Roles
| Role | Description |
|------|-------------|
| `resident` | Homeowner or tenant within the subdivision. |
| `admin` | Subdivision officer or HOA board member. |
| `guard` | Security personnel manning gates and emergency channels. |

## Out of Scope (v1)
- Payment gateway integration (planned for v2).
- Mobile native app.
